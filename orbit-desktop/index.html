日々の確認を、ひとつの場所に

必要な連携を選んで使えます。

01 / MAIL

メールと返信の確認

Gmailの読み取り専用連携、またはThunderbirdの「Orbit Mail Review」アドオンでメールを取得。PC内のルールで返信候補などを分類し、元のメールを開いて確認できます。

02 / CALENDAR

予定を見渡す

選択したGoogle Calendarの予定を表示します。追加・編集を利用するときだけ、別途編集権限を許可し、利用者の保存操作で反映します。

03 / TASKS

タスクを手元に

選択したGoogle Tasksリストのタスクと期限を表示します。追加・編集機能も、利用者が編集を有効にした場合に利用できます。

データと操作

自分のPCで確認。
必要な権限だけを許可。

  • Googleへの接続はGoogleの認証画面で許可します。OrbitがGoogleのパスワードを受け取ることはありません。
  • メールの自動送信・削除・既読変更は行いません。
  • 認証トークンと取得データのキャッシュは、Windowsユーザーに紐づく暗号化を使用してPC内に保存します。
  • メール分類はローカル処理です。メール・予定・タスクを外部AIへ送ったり、AIモデルの学習に使用したりしません。

分類は確認の手助けです。返信義務の確定や、すべてのメールの取得を保証するものではありません。詳しい取得範囲・保存・削除方法はプライバシーポリシーをご確認ください。

English overview

Your mail, calendar and tasks, close at hand.

Orbit Desktop is a personal Windows desktop application developed and operated by Shogo389. It displays mail review reminders, selected Google Calendar events and Google Tasks in desktop widgets. It is currently intended for the developer’s own use; this website does not offer public sign-up or downloads.

Gmail access is read-only. The optional Orbit Mail Review add-on reads mail from Thunderbird accounts and passes it to Orbit on the same PC. Classification runs locally, without sending content to an external AI service. Calendar and Tasks editing requires separate permission and an explicit save action. Mail is never automatically sent, deleted or marked as read by Orbit.
